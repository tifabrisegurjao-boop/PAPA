Contas de acesso ao SEI

Quando você clica em Entrar num processo do PAPA, esta extensão abre o SEI, faz o login com a conta do processo e abre o processo na lista de acessos externos. Para isso ela precisa da senha de cada conta — cadastre abaixo.

  • As senhas ficam só neste navegador, no armazenamento da extensão. Não vão para o PAPA, para o banco nem para a internet.
  • Elas só são digitadas na tela de login do SEI para o qual foram salvas, e só na aba que o PAPA abriu.
  • Se o SEI recusar o login, a extensão não tenta de novo (para não bloquear a conta). Se ele pedir o código da imagem, ela espera você digitar.
  • Quem usa este computador com o seu usuário do Windows consegue usar essas contas. Em computador compartilhado, não cadastre.
